# Аудит безопасности проекта Gunfire Airsoft Clone (Раунд 3)

Проведена финальная проверка кода после исправления критических уязвимостей. В настоящее время критические уязвимости (CSRF, IDOR, SQLi, отсутствие rate-limiting) устранены. Остались уязвимости низкого и среднего уровня, которые рекомендуется устранить для повышения общего уровня безопасности.

## 🟠 Средний уровень риска (Medium Severity)

### 1. Перечисление пользователей (User Enumeration)
**Компоненты:** `apps/accounts/forms.py` (CustomUserCreationForm)
**Описание:**
Стандартная форма регистрации Django `UserCreationForm` выбрасывает ошибку валидации, если пользователь с таким именем уже существует. Это позволяет злоумышленнику проверить наличие пользователя в системе.
**Риск:**
Сбор базы данных пользователей для последующих атак (брутфорс, фишинг).
**Рекомендация:**
Затруднить перечисление, либо приняв этот риск как допустимый для UX (удобнее знать сразу, что ник занят). Для полного устранения требуется изменение флоу регистрации (отправка письма-подтверждения без явного указания на существование аккаунта на экране).

## 🟡 Низкий уровень риска (Low Severity)

### 2. Отсутствие строгой валидации загружаемых файлов
**Компоненты:** `apps/catalog/models.py` (Product, ProductImage)
**Описание:**
Поля `ImageField` проверяют наличие валидного заголовка изображения, но не проверяют расширение файла или его содержимое на наличие вредоносного кода (хотя Django переименовывает файлы, снижая риск RCE).
**Риск:**
Загрузка "изображений", содержащих скрипты или эксплойты.
**Рекомендация:**
Использовать валидаторы (например, `FileExtensionValidator`).

### 3. Потенциальная ошибка фильтрации (Edge Case)
**Компоненты:** `apps/catalog/views.py`
**Описание:**
Во view `product_list`, фильтрация по `power_supply` и `manufacturer` берет данные напрямую из GET-параметров без валидации по белому списку допустимых значений (хотя это не SQLi, так как ORM экранирует параметры, это может замусорить логи или вызвать неожиданное поведение при передаче странных типов данных).
**Рекомендация:**
Валидировать входные параметры фильтров по списку `ALL_POWER_SUPPLIES` и `ALL_MANUFACTURERS`.

---
**Итог:** Критических проблем не обнаружено. Рекомендуется запланировать исправления указанных пунктов в порядке планового рефакторинга.
